このサイトについて

きっかけ図鑑は、Built with Claude: Japan 2026 に関連して公開されたプロジェクトを、作った人の立場と課題から整理した非公式のまとめです。AI を使って、自分の現場の困りごとに取り組む人の姿を知ってもらうために作りました。

掲載の基準

GitHub の公開リポジトリで、大会名を明記し、何を作ったのかが分かる説明のあるものを載せています。現在は初版で、作者の立場が README に書かれているプロジェクトを中心に載せています。

掲載が示さないこと

公式の名簿と照合していないため、掲載は選考通過や提出を示すものではありません。受賞の表示は、公式の発表を確認できたものに限ります。また、どのプロジェクトも短い期間で作られた試作で、事業として成立していることを示すものではありません。

文章の見分け方

本人の記述
作者が README に書いた内容です。
編集部まとめ
README をもとに、編集部が短くまとめた内容です。
未記載
README に書かれていない内容です。推測では補いません。

立場と課題の分類は、編集部が行いました。

個人情報の扱い

作者の氏名は掲載しません。README に書かれている場合も、立場だけを記し、作者のリポジトリにリンクしています。

掲載の取り下げ

ご自身のプロジェクトの掲載を取り下げたい場合は、次のフォームからお知らせください。確認でき次第、掲載を外します。

掲載の取り下げを申請する

申請は GitHub の Issue として公開されます。理由を書く必要はありません。
