Built with Claude: Japan 2026 の非公式まとめ

自分の現場から、作った人たち。

Built with Claude: Japan 2026 は、Anthropic と Cerebral Valley が開いた、日本に住む人のためのオンラインハッカソンです（2026年11月2日〜11月10日）。ここでは、大会名を明記して GitHub に公開されたプロジェクトを、作った人の立場から探して、解こうとした課題と一緒に読めるようにしました。

いま載っているのは 30 件、そのうちデモ動画を見られるのは 19 件です。

掲載は選考通過や提出を示すものではありません。大会の公式ページ
