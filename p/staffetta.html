STAFFETTA（スタフェッタ）

GitHub で見る
作った人本人の記述
愛知の中小のパン・ピザ工場の部長
解こうとした課題編集部まとめ
ばらばらの入口から届く注文を、事務の人が夜ごと手作業でまとめて発注につなげています。配送の順番や店ごとの納め方は、担当の人の記憶に頼っています。
作ったもの編集部まとめ
さまざまな入口から届くパンとピザの注文を 1 か所に集め、発注書、製造計画、配送のコース、請求書までつなげる受発注アプリです。FAX は Claude が読み取って迷った行だけを黄色で示すので、人は元の FAX と見比べて確定します。使う人に合わせて、大きな文字とやさしい日本語の画面にしています。

学べるところ編集部まとめ

迷った行だけ印を付け、人はそこを見比べる

  • AI の受け持ちは読み取りと印付けまでです。値を直すのも確定するのも人で、元の値と修正の履歴を残します。
  • 読み取りが合っていても、ほとんどの行に念のための黄色が付いた時期がありました。指示の文を例つきで書き直し、FAX を見ないと危ない行だけに絞っています。
  • 集計、換算、製造計画、税の計算には AI を使わず、ふつうのプログラムで行います。同じ入力なら必ず同じ結果になるようにするためです。
  • 作者はコードを書かず、困りごと、使う人、自動にしてよい範囲を声とスマホで伝え、担当ごとに分けた Claude Code を並行して動かしました。

短い期間で作られた試作です。事業として成立していることを示すものではありません。掲載は選考通過や提出を示すものでもありません。
