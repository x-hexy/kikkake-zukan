母と義母のために作った、エンジニアではない家族
解こうとした課題編集部まとめ
離れて一人で暮らす親の様子を毎日確かめるには、親が新しいアプリや操作を覚えなくても使える形が必要でした。
作ったもの編集部まとめ
毎朝 LINE で親に季節の挨拶を送り、親は声やボタンでひとこと返すだけの見守りの仕組みです。返事があったとき、正午まで返事がないとき、「ぐあいがわるい」が押されたときに、家族の LINE へ知らせが届きます。

学べるところ編集部まとめ

作りかけの段階で親に使ってもらい、そこから直す

  • 先に仕様書を書き、誰のために何をどの順で作るかを決めています。Claude Code は仕様にないことを勝手に決めず、選択肢を出して作者に選んでもらう形です。
  • 家族への知らせを増やしたくなったときは、親の負担と無料枠への影響を Claude Code に説明してもらい、1 時間に 1 回までという形を自分で選びました。
  • ファイルを書き換えるたびの検査と、コミット前の全テストを自動で走らせ、AI が書いたコードを AI に確かめさせています。
  • トークンなどの秘密の値はチャットに貼らず、ターミナルから直接登録する手順にしています。

短い期間で作られた試作です。事業として成立していることを示すものではありません。掲載は選考通過や提出を示すものでもありません。
